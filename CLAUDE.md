# Consulta CNPJ

Ferramenta gratuita de consulta de CNPJ.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- React 19

## API

- BrasilAPI: `https://brasilapi.com.br/api/cnpj/v1/{cnpj}`

## Hospedagem

- Vercel

## Monetização

- Google AdSense

## Padrões

- Server Components por padrão
- Mobile-first
- Idioma: Português do Brasil
- Sem dependências desnecessárias
- Seguir convenções do Next.js 15 (consultar `node_modules/next/dist/docs/` quando necessário)
